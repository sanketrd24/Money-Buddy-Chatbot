# Assets - Data

This folder contains data files for the Money Buddy app.

## Usage

Place JSON, CSV, or other data files here. Reference them in your code as:

```dart
final content = await rootBundle.loadString('assets/data/your_file.json');
```

## Examples

- `financial_data.json` - Additional financial information
- `quizzes.json` - Quiz questions and answers
- `concepts.json` - Financial concept definitions
