# 🚀 Money Buddy - GitHub Codespaces Quick Start

## 3-Step Setup

### Step 1: Create Codespace
1. Go to your GitHub repo
2. Click **Code** (green button)
3. Click **"Create codespace on main"**
4. Wait 2-5 minutes for setup

### Step 2: Run the App
In the terminal, type:
```bash
flutter run -d chrome
```

### Step 3: View in Browser
- Click the notification **"Open in Browser"**
- Or go to the **"Ports"** tab and click the forward arrow

---

## 📝 Terminal Commands

### Start the App
```bash
flutter run -d chrome
```

### Hot Reload (while app is running)
Press `r` in the terminal

### Hot Restart (rebuild everything)
Press `R` in the terminal

### Stop the App
Press `q` in the terminal

### Check Status
```bash
flutter doctor
```

### Clean & Rebuild
```bash
flutter clean
flutter pub get
flutter run -d chrome
```

## 🎨 Edit & Test Workflow

1. **Edit a file** in VS Code (left sidebar)
2. **Save the file** (Ctrl+S)
3. **Press `r`** in the terminal
4. **See changes instantly** in the browser! 🎉

## ❓ Common Issues

| Problem | Solution |
|---------|----------|
| "Flutter not found" | Run: `flutter doctor` |
| Port in use | Run: `flutter run -d chrome --web-port=8090` |
| App won't load | Press `R` for hot restart, or stop and restart |
| Terminal stuck | Press `Ctrl+C` to stop, then restart |
